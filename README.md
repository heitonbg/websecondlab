# Список задач – приложение по макету

Учебный проект: интерактивное приложение «Список задач» на HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек (в рамках лабораторной работы Л2).

- **Макет:** [To-Do List (Community) на Figma](https://www.figma.com/design/U09ss0BkhIpaSLm05v0AQ7/To-Do-List-(Community))

## Возможности

В ходе выполнения работы реализован следующий функционал:
- **Добавление задач:** через форму с полями Title (заголовок) и About (описание), а также с возможностью указать время (дедлайн). Пустой ввод блокируется с выводом сообщения об ошибке.
- **Отметка выполнения:** задача перечеркивается, статус меняется в `localStorage`.
- **Редактирование:** через модальное окно (по кнопке в меню). Сохранение по кнопке Save или клавише Enter, отмена — по Cancel или Escape.
- **Удаление:** с подтверждением в отдельном модальном окне (как в макете).
- **Сохранение:** все данные (включая время) сохраняются в браузере и восстанавливаются после перезагрузки страницы.
- **Пустое состояние:** отдельный экран «No tasks» при отсутствии задач.
- **Безопасность:** ввод пользователя выводится только через `textContent` (защита от XSS).
- **Доступность:** управление с клавиатуры, ARIA-атрибуты для кнопок-иконок, скрытые подписи для полей ввода.

## Запуск локально

Из-за политики безопасности браузеров (CORS) приложение с ES-модулями не запускается при открытии файла `index.html` двойным кликом. Используйте локальный сервер:

**Вариант 1 (VS Code):**
1. Установите расширение **Live Server**.
2. Нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.
