# Список задач – приложение по макету

Учебный проект: приложение на HTML, CSS и JavaScript без фреймворков.

- Макет: [To-Do List (Community)](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7/To-Do-List-(Community))

## Запуск локально
Для работы ES-модулей требуется локальный сервер (из-за политики CORS браузера).
1. Откройте проект в VS Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.

## Принятые решения
- Поведение пустого состояния: текст "No tasks" с декоративной линией, как на макете.
- Сообщение об ошибке: выводится красным текстом под полем ввода.
- Длинный текст: переносится благодаря `overflow-wrap: anywhere`.
- Редактирование: реализовано через модальное окно (как на макете "iPhone 14 Edit Task").
